# Проект NewProjectForPZ

## Описание
Данный репозиторий создан в рамках выполнения практического задания по Git.
В проекте используется модель ветвления **Git Flow**.

## Инструкция по запуску
1. Клонируйте репозиторий:
   git clone https://github.com/Dikavs/NewProjectForPZ
2. Перейдите в папку проекта:
   cd NewProjectForPZ
3. Переключитесь на ветку разработки:
   git checkout develop
